# Synthetic sample documents

Every name, address, email, phone number, IBAN, card number and ID in this folder is **fictional**.
Values were chosen to be obviously fake or taken from reserved/documentation ranges:

- emails use `example.com`, `example.org` and `example.net` (reserved by RFC 2606)
- UK phone numbers use Ofcom's drama range (`020 7946 0xxx`); US numbers use `555-01xx`
- IBANs are the published documentation examples from the IBAN standard (checksums are valid)
- card numbers are the publicly documented test numbers of payment providers (Luhn-valid, not real accounts)

| File | Shows |
|---|---|
| `sample-customer-record.md` | Markdown with a person, contact details, address, date of birth and an IBAN |
| `sample-support-ticket.txt` | Email-style ticket with names, phone numbers and a card number |
| `sample-invoice.txt` | Business document: company names and invoice dates (mostly *not* personal data) |
| `sample-employee-record.md` | HR record with IDs, tax and passport numbers |
| `sample-ambiguous-notes.txt` | Deliberately ambiguous text ("Jordan works with Amazon in Berlin") to demonstrate false positives and why human review matters |
| `sample-medical-referral.pdf` | PDF version (generated by `make_sample_pdf.py`) to exercise PDF extraction and sanitised PDF output |
